# Front Google Personal Calendar

The Front platform has a calendar email system but it only works if you have a Microsoft work account or Google Workspace. This sidebar plugin allows free tier Google accounts to save meetings to a calendar in Google calendar.

## Installation

In Front, add a sidebar plugin and set the URL field to https://connorjbryant.github.io/front-google-personal-calendar/?refresh=1
